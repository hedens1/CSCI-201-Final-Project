# CSCI-201-Final-Project
This repo will store the information needed to complete my Computer Science 201 course

An important note for this project was that through researching best practices, I found that "using namespace std" is bad practice in header files. 

This project focuses on creating and utilizing a library management system. This would include things like searching for books by title, genre, or author. It would also include finding a patron or keeping track of whether or not a book is checked out. 
This system would also keep track of printed versions of a book versus an ebook.
